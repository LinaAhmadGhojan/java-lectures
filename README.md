# محاضرات جافا (Java Lectures)

مستودع لمحاضرات الجافا (عملي برمجة 3): ملفات الشرح (PDF) والأكواد الجاهزة للتشغيل.
سأضيف محاضرة جديدة هنا بعد كل جلسة.

## المحاضرات

| المحاضرة | الموضوع | الرابط |
|---|---|---|
| 1 | مراجعة: أساسيات Java + البرمجة غرضية التوجه (OOP) + التمرين 1 | [lecture-01](lecture-01/) |
| 2 | الأشكال الهندسية: من الواقع إلى الكود (الصف والغرض والتابع، الوراثة، `abstract`، تعدد الأشكال) | [lecture-02](lecture-02/) |
| 3 | مطعم: الوراثة والواجهات والتركيب والتجميع والارتباط (مراجعة شاملة) | [lecture-03](lecture-03/) |
| 4 | Generics: الصف العام والدالة العامة والواجهة العامة، `Type Safety` و`Type Erasure` | [lecture-04](lecture-04/) |
| 5 | Wildcards: الثبات `Invariance` و`?` و`? extends` و`? super` وقاعدة `PECS` ومعاملات النوع بشرط `T extends` | [lecture-05](lecture-05/) |

## كيف أستعمل المستودع؟

1. افتح مجلد المحاضرة (مثلاً `lecture-01`).
2. اقرأ ملفات الشرح من مجلد `files/` بالترتيب (الأرقام في أول اسم الملف).
3. شغّل الكود من مجلد `code/` (التعليمات داخل README كل محاضرة).

> نزّل المستودع كاملاً: اضغط زر **Code** الأخضر ثم **Download ZIP**، وفك الضغط في مسار **إنجليزي** (مثل `C:\java-lectures`).
