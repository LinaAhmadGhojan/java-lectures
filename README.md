سأضيف محاضرة جديدة هنا بعد كل جلسة.

## كيف أستعمل المستودع؟

1. افتح مجلد المحاضرة (مثلاً `lecture-01`).
2. اقرأ ملفات الشرح من مجلد `files/` بالترتيب (الأرقام في أول اسم الملف).
3. شغّل الكود من مجلد `code/` (التعليمات داخل README كل محاضرة).

> نزّل المستودع كاملاً: اضغط زر **Code** الأخضر ثم **Download ZIP**، وفك الضغط في مسار **إنجليزي** (مثل `C:\java-lectures`).
