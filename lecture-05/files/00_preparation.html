تحضير المحاضرة الخامسة: Wildcards

قبل الحصة، حوالي 10 دقائق، قبل فتح الشرائح

1) استرجاع سريع للمحاضرة الماضية (3 دقائق)

اسأل الطلاب بصوت عالٍ، وخذ جواباً أو اثنين لكل سؤال:

  • شو الفرق بين Box<String> وBox<Integer>؟ (نفس الصف، نوع مختلف بداخله)
  • شو فايدة الـ Generics مقارنة بـ Object؟ (الخطأ يظهر عند الترجمة وليس عند التشغيل)
  • شو يعني T؟ (مكان فاضي لنوع نحدده وقت الاستعمال)

2) الوراثة بدقيقتين (قبل أي كود جديد)

class Animal { }
class Dog extends Animal { }
class Cat extends Animal { }

Animal a = new Dog();   // مقبول: الكلب هو حيوان

اكتب على السبورة بجانب الكود: الكلب هو حيوان. هذه العلاقة بين حيوانين. لا تنتقل للنقطة التالية قبل أن يؤكد الجميع أنها واضحة.

3) السؤال اللغز (بدون تصحيح)

الكلب هو حيوان. فهل صندوق الكلاب هو صندوق حيوانات؟

اطلب رفع الأيدي: نعم أو لا. لا تصحّح ولا تعلّق، وقل لهم: «بنعرف الجواب بالشريحة الثانية، وبنعرف ليش».

الجواب المتوقع منهم أغلب الأحيان «نعم»، وهذا سبب أن الدرس مهم: الجواب الصحيح لا.

4) فكرة القفصين (احفظها قبل الحصة)

قفص لافتته «كلاب فقط»، وقفص ثاني لافتته «أي حيوان». الكلب حيوان، لكن هذا لا يجعل القفصين نفس الشيء: لو اعتبرنا قفص الكلاب قفص حيوانات، أحدهم سيضع قطة فيه، وعندها ينهار البرنامج. هذا بالضبط ما تمنعه Java.

5) خريطة الحصة (7 عناوين)

#العنوانبكلمة وحدة
1الثبات InvarianceBox<Dog> ليس Box<Animal>
2الرمز ?أي نوع، لا يهمني
3? extendsللقراءة: النوع أو من يرث منه
4? superللكتابة: النوع أو من فوقه
5قاعدة PECSالمنتج extends والمستهلك super
6T extendsمعامل نوع بشرط (صف أو interface)
7Wildcard أم T؟أحتاج اسم النوع أم لا

بعدها 6 تمارين محلولة. لا تدخل بتفاصيل المجموعات Collections الآن، فهي في المحاضرة القادمة.
