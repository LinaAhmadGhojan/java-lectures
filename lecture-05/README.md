# المحاضرة 5: Wildcards (الأنواع العامة المرنة)

لماذا `Box<Dog>` ليس `Box<Animal>` (الثبات `Invariance`)، ثم الرمز `?` و`? extends` و`? super` وقاعدة `PECS`، ثم معاملات النوع بشرط `T extends` ومتى نفضلها على الـ wildcard.

## الملفات (`files/`)

| الملف | ما هو |
|---|---|
| `00_preparation.html` | تحضير قبل المحاضرة (للأستاذ): استرجاع المحاضرة الماضية، السؤال اللغز، خريطة الحصة |
| `01_wildcards_lecture.pdf` | الشرح الكامل مع التمارين الستة المحلولة سطراً بسطر والخلاصة |
| `wildcards_interactive.html` | الشرائح التفاعلية: الأستاذ يرسم ويؤشّر على الكود خطوة خطوة |

اقرؤوا ملف PDF أولاً، ثم جرّبوا الشرائح التفاعلية.

## كيف أفتح الشرائح التفاعلية؟

نزّل الملف `wildcards_interactive.html` وافتحه بالمتصفح (Chrome أو Edge). الأسهم `→` و`←` للتنقل، و`M` لقائمة الشرائح، و`F` لملء الشاشة.
