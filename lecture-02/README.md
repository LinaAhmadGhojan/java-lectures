## ▶️ كيف أشغّل الكود؟ (جاهز مباشرة)

> **مهم:** ضع المجلد في مسار **إنجليزي بالكامل** (مثل `C:\java-lectures`). المسار الذي فيه حروف عربية يسبب الخطأ `Could not find or load main class`.

### الطريقة 1: بنقرة واحدة (الأسهل)
- **Windows:** افتح مجلد `lecture-02/code` وانقر مرتين على الملف **`run.bat`**.
- **Linux / macOS:** من داخل `lecture-02/code` اكتب: `sh run.sh`

تظهر قائمة بأرقام الأمثلة. اكتب الرقم واضغط Enter:

```
  1) Without abstract: Shape returns 0.0   (what goes wrong)
  2) With abstract: Shape (the solution)   (the input is read from input.txt)
  3) With abstract: Shape (the solution)   (you type the input yourself)
  4) Common mistake: area as an attribute (wrong) vs as a method (right)
  0) Exit
```

قبل تشغيل كل مثال تطبع القائمة **اسم المجلد والملف** الذي فيه الكود، فافتحه واقرأه.

### 📝 الإدخال جاهز في ملف `input.txt`
**الرقم 2** يقرأ الإدخال من الملف [`code/input.txt`](code/input.txt) ويعرضه بالأخضر:

```
1      ← نوع الشكل (1 دائرة، 2 مستطيل، 3 مربع)
5      ← نصف القطر
```

**جرّب بنفسك:** افتح `input.txt` وغيّر القيم، ثم شغّل الرقم 2 من جديد. مثلاً للمستطيل:

```
2
4
6
```

- إذا حذفت الملف أو لم تجده، يطلب منك البرنامج أن تكتب الإدخال بنفسك.
- **الرقم 3** يشغّل نفس البرنامج (الحل) وتكتب الإدخال بلوحة المفاتيح.

### 🔬 تجربة مهمة: لماذا `abstract`؟
1. شغّل **الرقم 1** (بدون `abstract`): سترى أن `Rectangle` (نسي كاتبه `getArea`) يطبع المساحة `0.0` بدل 24 **بدون أي خطأ**.
2. افتح `v2_abstract/Shape.java`، وجرّب أن تكتب في أي مكان `new Shape();` أو أن تنشئ صفاً يرث من `Shape` ولا يكتب `getArea()`: ستظهر رسالة خطأ **فوراً** في الترجمة. هذا ما يحميك.

### الطريقة 2: IntelliJ IDEA
1. `File` ← `Open` ← اختر المجلد **`lecture-02/code`**.
2. إذا ظهر شريط أصفر "Project SDK is not defined": اضغط **Setup SDK** واختر JDK (الإصدار 8 أو أحدث).
3. شغّل الإعداد **MainMenu** (السهم الأخضر أعلى اليمين)، أو افتح أي ملف فيه `main` واضغط السهم الأخضر بجانبه.

### الطريقة 3: سطر الأوامر
من داخل `lecture-02/code`:

```bash
javac -encoding UTF-8 -sourcepath src -d out src/launcher/MainMenu.java
java -cp out launcher.MainMenu
```

### المتطلبات
- **JDK** (وليس JRE فقط): الإصدار 8 أو أحدث. للتحميل: <https://adoptium.net>
- للتأكد: افتح سطر الأوامر واكتب `javac -version`
